# Чеклист самопроверки (Фаза 5 харнесса)

Пройдись по каждому разделу применительно к своему диффу.
Проваленный пункт — либо исправь, либо обоснуй в отчёте, почему исправить нельзя.
Отметки [ ] оставляй как есть — это шаблон для прогона, а не для заполнения вручную.

## Ошибки

- [ ] Все ошибки обработаны: нет проигнорированных `err` (в том числе `_ = err`)
- [ ] Ошибки оборачиваются с контекстом: `fmt.Errorf("load user %d: %w", id, err)`
- [ ] Нет ошибок, проглоченных пустым `if err != nil {}`
- [ ] Сообщения об ошибках на границе API не раскрывают внутренности (SQL, пути, стеки)

## Контекст и конкурентность

- [ ] `context.Context` — первый параметр у функций, делающих I/O
- [ ] Контекст пробрасывается вниз, а не создаётся заново посередине
- [ ] Горутины не утекают: выход по `ctx.Done()` или закрытому каналу
- [ ] Где нужен ожидание горутин — есть `sync.WaitGroup`
- [ ] Канал закрывает отправитель, не получатель; нет записи в закрытый канал
- [ ] Общее состояние защищено мьютексом; конкурентный код прогнан с `-race`

## Ресурсы

- [ ] Все `Close` / `Unlock` / `Rollback` — в `defer` сразу после захвата
- [ ] Тикеры и таймеры останавливаются (`ticker.Stop()`)
- [ ] Нет утечек соединений (БД, HTTP-клиенты переиспользуются)

## Код

- [ ] Именование как в окружающем коде, без транслита
- [ ] Повторяющиеся или неочевидные значения вынесены в константы
- [ ] Нет мёртвого кода и закомментированных кусков
- [ ] Публичные сущности библиотечных пакетов задокументированы godoc-комментарием
- [ ] Логирование через логгер проекта, не `fmt.Println`
- [ ] Функции короткие и делают одну вещь; глубокая вложенность разбита ранними возвратами

## Тесты

- [ ] Новая логика покрыта тестами, включая ошибочные ветки
- [ ] Случаев больше двух — тесты table-driven
- [ ] Тесты не зависят от порядка запуска и внешнего состояния
- [ ] Существующие тесты, задетые изменением, обновлены

## Безопасность

- [ ] Нет секретов в коде, тестах и конфигах — только env
- [ ] Входные данные на границах API валидируются
- [ ] SQL-запросы параметризованы, нет конкатенации строк в запросах

## Дифф

- [ ] Изменения минимальны и относятся только к задаче
- [ ] Нет случайных переформатирований и переименований
- [ ] Миграции БД (если есть) совместимы со старым кодом
